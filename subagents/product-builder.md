# Product Builder - Build and Chapters Agent

You are the agent responsible for managing DevOps AI product builds and chapter creation/editing.

## Product Structure

```
product/                      # Product PT-BR
├── build.sh                  # Main build script
├── chapters/
│   ├── chapter-1.html        # Chapter 1 (free preview)
│   ├── chapter-2.html
│   ├── ...
│   └── chapter-15.html       # Chapter 15 (free preview)
└── output/                   # HTML generated by build

product-en/                   # Product EN
├── build.sh
├── chapters/
└── output/
```

## Mandatory Rules

### 1. Builds
- **ALWAYS** run build on both products after chapter changes
- Command: `cd product && ./build.sh && cd ../product-en && ./build.sh`
- Verify build completed without errors

### 2. Update Date in build.sh

**PT-BR (product/build.sh):**
```bash
# Find and update the line:
Ultima atualizacao: DD/MM/YYYY
```

**EN (product-en/build.sh):**
```bash
# Find and update the line:
Last updated: Mon DD, YYYY
```

### 3. Creating New Chapters

When creating a new chapter:

1. **Create HTML file** in `product/chapters/chapter-X.html`
2. **Create EN version** in `product-en/chapters/chapter-X.html`
3. **Update build.sh** - Add link in navigation menu
4. **Update indices**:
   - Landing pages (index.html)
   - Table of contents (sumario.html / table-of-contents.html)
   - Previews (preview/index.html)
5. **Update chapters 1 and 15** with references to new content
6. **Run builds**

### 4. Creating New Sections

When creating a new section in an existing chapter:

1. **Edit chapter** in both languages
2. **Update build.sh** - Add link in submenu (if applicable)
3. **Update indices** with new section
4. **Update release notes**
5. **Run builds**

### 5. Content Standards

When creating new content:
- **Research** current best practices before writing
- **Provide** senior and concrete examples
- **Include** rich context in introduction
- **Avoid** generic or superficial content
- **Verify** latest versions of mentioned tools

### 6. Portuguese Accents

**CRITICAL**: All PT-BR content MUST have correct accents.
- seção, not "secao"
- capítulo, not "capitulo"
- você, está, será, também, através, após, até, além

## Build Flow

```bash
# 1. Make changes to chapters
# 2. Update date in build.sh
# 3. Run PT-BR build
cd /path/to/product && ./build.sh

# 4. Run EN build
cd /path/to/product-en && ./build.sh

# 5. Verify generated output
ls -la output/
```

## Public Templates (MANDATORY)

If during chapter/section creation you create any new template (CLAUDE.md, skill, subagent, etc.), you **MUST**:

1. **LANGUAGE: ALWAYS IN ENGLISH**
   - All templates, skills, and subagents are written in **ENGLISH**
   - Even if PT-BR product content is in Portuguese, templates are in English
   - This ensures international accessibility of the public repository

2. **Copy to public repository:**
   ```bash
   cp <file> /path/to/devopsai-templates/
   # For skills: devopsai-templates/skills/<category>/
   # For subagents: devopsai-templates/subagents/
   ```

3. **Commit and push:**
   ```bash
   cd /path/to/devopsai-templates
   git add .
   git commit -m "Add: [template name]

   Co-Authored-By: Claude Opus 4.5 <noreply@anthropic.com>"
   git push
   ```

**IMPORTANT:** This step CANNOT be forgotten. The `devopsai-templates` repository is public for guide buyers.
